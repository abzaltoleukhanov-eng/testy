# Скиллы Nordace: Creative Strategy и Media Buying Analyst

Два скилла Claude для работы креатив-стратега и медиабайера Nordace.

| Скилл | Что делает | Когда вызывается |
|---|---|---|
| `creative-strategy` | Полный путь от ресерча до скрипта. Сбор реальных отзывов со ссылкой на каждый (Reddit, YouTube, Trustpilot, Mumsnet, форумы, Facebook-группы через твой браузер, скриншоты) → проверка, что цитата дословная → кластеры болей, желаний, возражений → инсайты с контрдоводами и вердиктом скрипта → осведомлённость и изощрённость рынка → персоны и их речь → концепты «персона × угол × оффер» → хуки → приоритеты и план теста → скрипт и бриф. Всё пишет в Google таблицы. | «сделай ресерч по Comino Totepack», «что пишут люди про тоуты для путешествий», «найди углы для Lévant Tote», «напиши скрипт», «бриф для UGC» |
| `media-buying-analyst` | Разбор скриншотов из Meta Ads Manager: hook rate, hold rate, CTR, CPA, ROAS, где ломается воронка, вердикт (выключить / ждать / итерация / масштабировать), путь к бонусу. | скриншот Ads Manager + «разбери», «выключать или нет?» |

Работа идёт по этапам (0–11). После каждого этапа скилл показывает карточку с результатом и решением, которое принимаешь ты, и ждёт твоего «да» или правок. Одобренные этапы записываются в проект, поэтому ресерч можно продолжить в другой день. Без остановок он идёт, только если попросишь сам.

`creative-strategy` заменил два прежних скилла, `creative-research` и `research-engine`. Он собран из методики курса Creative Strategy (NSY, Шварц, Левинджер, Motion 2026, Хормози) и механики доказательного ресерча (статусы источников, контрдоводы, независимость, журнал запросов, цикл обучения). Данные старых ресерчей остались в `research/`.

## Откуда берутся отзывы
| Площадка | В облаке (claude.ai/code) | На твоём компьютере |
|---|---|---|
| Reddit | да: архив Arctic Shift, тред целиком, ссылка на каждый комментарий | да |
| YouTube | да: yt-dlp, комментарии со ссылками, субтитры | да |
| Форумы без защиты от ботов (MoneySavingExpert и др.) | да, полный текст | да |
| Trustpilot, Mumsnet | короткие точные фразы через WebFetch, подтверждаются вторым чтением | полный текст через браузер |
| Facebook-группы, Meta Ad Library, Amazon, сайт Nordace | нет | да, через Claude in Chrome под твоим логином, или скриншоты |

Подробно: `skills/creative-strategy/references/access.md`. Для полного ресерча с Facebook-группами запускай Claude на компьютере с расширением Claude in Chrome.

## Где работают
- **Claude Code** (claude.ai/code в браузере, мобильное приложение, десктоп): ничего ставить не нужно. Скиллы лежат в `.claude/skills/` этого репозитория и подгружаются сами в любой сессии с репо `testy`. Данные ресерчей сохраняются в `research/<ID>/` и коммитятся.
- **Обычный чат claude.ai**: Settings → Capabilities → Skills → Upload skill, архивы `dist/creative-strategy.zip` и `dist/media-buying-analyst.zip`. Сборщику нужен доступ кода в интернет (Settings → Capabilities); без него работает только с тем, что ты пришлёшь.
- Для записи в таблицы должны быть включены коннекторы Google Drive и Google Sheets.

Исходники в `skills/`. После правок запусти `./build.sh`: он проверит скиллы, обновит `.claude/skills/` и архивы в `dist/`.

## Google таблицы
Папка **Nordace · Creative Research** в Google Drive:
- **Nordace · Creative Research HQ**: генеральная таблица. Вкладки `Продукты`, `Ресерчи`, `Боли`, `Желания`, `Возражения`, `Углы`, `Концепты`, `Разборы рекламы`.
- **Nordace · Research Template**: шаблон одного ресерча. Вкладки `Сводка`, `Продукт`, `Источники`, `VOC`, `Кластеры`, `Конкуренты`, `Инсайты`, `Персоны`, `Углы`, `Концепты`, `Скрипт`, `Запросы`, `Форматы`, `Хуки`, `Тесты`.

## Структура
```
skills/
  shared/nordace-brand.md            бренд, продукты, критерий победителя (копируется в оба скилла)
  creative-strategy/
    SKILL.md                         порядок работы, правила, режимы
    references/                      доступ к источникам, сбор, разметка, продукт, конкуренты и форматы,
                                     анализ, персоны и речь, концепты, хуки, приоритеты и тест,
                                     скрипт и бриф, схема таблиц
    scripts/voc.py                   сборщик и проверка: Reddit, YouTube, страницы, WebFetch, браузер,
                                     дословная сверка цитат, статистика, вердикт инсайтов, экспорт в таблицу
  media-buying-analyst/
    SKILL.md
    references/                      метрики, ориентиры, диагностика, learning phase, правила решений, мои KPI
research/<ID>/                       данные ресерчей (источники, цитаты, запросы)
.claude/skills/                      собранные скиллы для Claude Code (генерируется build.sh)
dist/                                готовые .zip для загрузки в claude.ai
build.sh                             проверка и сборка
scripts/validate_skill.py            валидатор скиллов
```

## Что дозаполнить
- `skills/shared/nordace-brand.md`: цены и фичи четырёх продуктов, список стран.
- `skills/media-buying-analyst/references/my-kpis.md`: AOV по продуктам, окно атрибуции для бонуса, средние по аккаунту.
