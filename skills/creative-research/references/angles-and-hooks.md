# Углы и хуки

## Как получить углы из инсайтов
Угол: причина купить, сформулированная для конкретной персоны. Один инсайт обычно даёт 2–4 угла.

Строй матрицу во вкладке «Углы»:

| Угол | Персона | Боль/желание (кластер, частота) | Уровень осведомлённости | Почему сработает | Доказательство из продукта | Есть у конкурентов? | Приоритет |

Приоритет считай по трём вопросам (по 1–3 балла):
1. **Масштаб**: насколько массовая боль/желание (частота кластера, широта персоны). Важнее всего, потому что победителю нужно $50–100k спенда.
2. **Пробел**: делают ли так конкуренты (3 = никто, 1 = все).
3. **Доказуемость**: можем ли показать это в ролике (3 = видно в кадре за 3 секунды).

## Типы углов (библиотека для сумок)
Используй как подсказки, а не как шаблон. Каждый угол должен опираться на кластер из VOC.

| Тип | Суть | Пример |
|---|---|---|
| Проблема → решение | назвать боль и показать решение | «Плечо болит от тоута с ноутбуком? Превращаем в рюкзак» |
| Ручная кладь / personal item | лоукосты берут плату за багаж | «Влезает под сиденье, а вмещает на 5 дней» |
| Одна вместо многих | заменяет несколько сумок | «Офис → спортзал → самолёт: одна сумка» |
| Порядок в хаосе | всё на своих местах | «Больше никогда не ищу ключи на дне сумки» |
| Безопасность | антивор, скрытые карманы | «Пикпокеты в Риме? Молния у спины» |
| Сравнение / дорогой аналог | против известного бренда | «Как Béis, только в 2 раза дешевле и превращается в рюкзак» |
| Демонстрация вместимости | «что влезает» | «Упаковала 5 дней отпуска в тоут» |
| Идентичность | кем я становлюсь с этой сумкой | «Для женщин, которые путешествуют сами» |
| Подарок / сезон | повод купить сейчас | «Подарок маме, который она будет носить каждый день» |
| Социальное доказательство | масса отзывов, реакции | «12 000 женщин сменили сумку…» |
| Возражение в лоб | снять главный страх | «Думала, развалится через месяц. Год спустя…» |
| Ошибка / анти-совет | «перестань делать X» | «Хватит носить ноутбук в обычном тоуте» |

## Хуки
Хук решает, досмотрят ли первые 3 секунды (это hook rate в медиабайинге). Для каждого концепта пиши 3–5 вариантов разных типов, чтобы тестировать:

| Тип хука | Пример |
|---|---|
| Узнавание боли словами клиента | "If your shoulder hurts by 3pm, it's your bag." |
| POV / ситуация | "POV: you're about to pay €60 for a carry-on…" |
| Вопрос | "Why does every tote bag destroy your back?" |
| Неожиданное действие в кадре | тоут за секунду превращается в рюкзак |
| Сравнение | "My $400 bag vs. this one" |
| Список / демонстрация | "Everything I fit in my personal item for 7 days" |
| Отзыв-цитата | дословная фраза из VOC на экране |
| Контринтуитивное утверждение | "Stop buying travel backpacks." |

Правила хуков:
- Берите дословный язык из VOC (цитаты с силой 3), он звучит как человек, а не как реклама.
- Визуальный хук важнее текстового: многие смотрят без звука, первый кадр должен быть понятен без слов.
- Один хук = одна мысль.
- Хуки одного концепта должны отличаться типом, иначе тест ничего не покажет.
