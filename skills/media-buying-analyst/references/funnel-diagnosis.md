# Диагностика воронки: симптом → причина → действие

Воронка: **Показ → Хук → Удержание → Клик → Посадка → Покупка**. Ищи первое по порядку слабое звено: проблемы ниже него часто его следствие.

| Симптом | Вероятная причина | Что делать |
|---|---|---|
| Низкий hook rate (< 20%) | первые 1–3 с не останавливают скролл: нет узнаваемой ситуации, медленный старт, логотип в начале, непонятно без звука | 3–5 новых хуков с тем же телом ролика; визуальное действие в первом кадре; дословная фраза клиента на экране; взять сильнейшие цитаты из ресерча |
| Хороший hook, низкий hold | хук обещает одно, ролик даёт другое; затянутая середина; продукт появляется поздно | сократить середину, менять кадр каждые 2–3 с, показать продукт к 3–5 с, проверить, что тело ролика продолжает обещание хука |
| Хороший hook и hold, низкий CTR | зрителю интересно, но нет причины кликнуть: слабый CTA, не показана выгода, нет оффера, развлекательный ролик без продажи | усилить CTA, показать главную выгоду и доказательство, добавить причину кликнуть сейчас (оффер, ограничение) |
| Высокий CTR, низкий hook | ролик хорошо продаёт тем, кто досмотрел, но мало кто досматривает | сохранить тело, менять только хук: потенциал масштаба высокий |
| Высокий CTR, мало покупок | проблема после клика: страница, цена, доставка, несоответствие ролика и страницы | проверить LPV rate, скорость сайта, соответствие обещания ролика и посадочной, цену и доставку в нужной стране. Креатив может быть ни при чём |
| Низкий LPV rate (< 70%) | медленный сайт или случайные клики (часто в Audience Network) | проверить скорость сайта, срез по плейсментам |
| Много ATC, мало покупок | возражения на этапе оформления: доставка, итоговая цена, доверие | сказать пользователю, что это вопрос оффера и сайта; в ролике снять возражение о доставке/возврате |
| Высокий CPM при нормальном CTR | дорогая страна или сезон, узкая аудитория, низкая оценка качества | срез по странам; если CPA в норме, CPM не важен |
| ROAS падает по мере роста спенда | креатив исчерпал «тёплую» часть широкой аудитории | новые хуки и вариации угла, проверить частоту |
| Частота > 3.5, CTR падает, CPM растёт | выгорание креатива | обновить хуки, новые форматы того же угла, не повышать бюджет |
| Мало спенда у объявления в Advantage+ / CBO | алгоритм отдаёт бюджет другому объявлению | не судить по нему; если нужно проверить, тестировать в отдельной кампании |
| Хорошие цифры, но мало данных | рано | ждать до порогов из `decision-rules.md` |

## Срезы, которые помогают понять причину
- **Age / Gender**: кому заходит. Если покупают в основном 55+, а ролик снят для 25-летних, это сигнал для ресерча.
- **Country**: где ROAS выше, где CPM дороже.
- **Placement**: Reels vs Feed vs Stories. Вертикальное видео без адаптации под Reels теряет hook rate.
- **Date (по дням)**: держится ли ROAS при росте спенда.

## Сравнение нескольких объявлений
Если на скриншоте несколько креативов, сделай таблицу «креатив × hook / hold / CTR / CPA / ROAS» и скажи:
- какой лучший по каждому этапу воронки;
- какие элементы можно скрестить (хук от одного + тело от другого);
- кто кандидат в победители по критерию бонуса.
