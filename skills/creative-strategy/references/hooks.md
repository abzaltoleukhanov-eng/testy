# Хуки

Хуки пишутся после того, как концепт стоит на инсайте. Хук без концепта — заголовок без статьи.

## Три задачи (все обязательны)
1. Остановить скролл.
2. Сказать «это для тебя».
3. Дать причину смотреть дальше (открытая петля).

Хук, который только останавливает, приводит «не тех»: высокий hook rate при низкой конверсии.

## Три слоя
- **Визуал:** первый кадр, движение, действие с продуктом.
- **Текст на экране.**
- **Звук и речь.**

Слои говорят одно или дополняют друг друга и работают без звука: многие смотрят Reels беззвучно. Визуальный хук важнее текстового.

## Типы
| Тип | Пример |
|---|---|
| Обращение к аудитории | «If you carry a laptop in a tote…» |
| Боль словами покупателя | "If your shoulder hurts by 3pm, it's your bag." |
| Смелое утверждение | "Stop buying travel backpacks." |
| Вопрос | "Why does every tote bag destroy your back?" |
| Против общего мнения | «Органайзеры делают сумку хуже» |
| Факт / цифра | только проверенная |
| Демонстрация / визуальный | тоут за секунду становится рюкзаком |
| История / POV | "POV: you're about to pay €60 for a carry-on…" |
| Сравнение / враг | "My $400 bag vs. this one" |
| Результат | «7 дней в personal item» |
| Отзыв-цитата | дословная фраза из VOC на экране (со ссылкой в брифе) |
| «Stop scrolling if…» | "Stop scrolling if you've ever dumped your bag out at security" |

Тип хука подбирай по уровню осведомлённости (`analysis.md`): для Unaware — ситуация и история, для Solution Aware — сравнение и механизм.

## Карточка хука (вкладка `Хуки`)
| Поле | Что писать |
|---|---|
| Концепт | ID |
| Тип и механизм | почему остановит именно эту персону: узнавание, любопытство, несогласие, ирония… |
| Реплика (речь) | первые слова |
| Первый кадр | что видно и что происходит |
| Текст на экране | 3–7 слов |
| Откуда слова | ID цитаты VOC, если язык взят у покупателя |
| Обещание | что зритель ждёт дальше, и где тело ролика это выполняет |
| Референс | ссылка на реальный пример похожего открытия (статус просмотра) |
| Риск | кого может привлечь «не того», где переобещание |
| Что тестируем | одна переменная |

## Правила
- На концепт 3–5 хуков **разных типов**: синонимы одной конструкции тест не различит.
- Слова бери из цитат силы 3: так реклама звучит как человек.
- Один хук = одна мысль.
- **Хук и тело совпадают:** обещание выполнено, уровень осведомлённости тот же, персона та же.
- Никаких «viral» и «тренд» без даты и ссылки. Пример хука — это `ГИПОТЕЗА`, а не доказательство.

## Ошибки
- медленный старт (логотип, «Hey guys»);
- хук не связан с телом (кликбейт снижает оценку объявления в аукционе);
- переобещание;
- общий хук («изменит твою жизнь»);
- слои спорят друг с другом;
- молодёжный сленг у зрелого героя;
- выдуманный отзыв.
