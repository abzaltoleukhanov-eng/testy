# Скрипт и бриф

## 1. Скелет (beat sheet)
| Секунды | Блок | Кадр (что видно) | Текст на экране | Речь / voice-over | Зачем |
|---|---|---|---|---|---|
| 0–3 | Хук | | | | остановить, «это для тебя» |
| 3–10 | Проблема | | | | узнавание |
| 10–18 | Почему прошлое не сработало | | | | снять недоверие (стадия 4+) |
| 18–30 | Решение и механизм | | | | почему работает |
| 30–40 | Доказательство | | | | поверить |
| 40–45 | Оффер и CTA | | | | действие сейчас |

Тайминги — ориентир, для 15–30 с блоки сжимаются. Колонка **«Зачем»** обязательна: по ней исполнитель принимает решения о темпе и кадрах.

Правила:
- продукт в кадре к 3–5 секунде для холодной аудитории (если концепт не Unaware-история);
- что-то новое каждые 1–2 секунды: склейка, движение, текст. «If there is ever a hint of boredom, I cut it» (MrBeast, цитата в NSY);
- текст на экране дублирует главную мысль;
- одна главная выгода на ролик;
- каждое фактическое утверждение с пометкой источника (ID цитаты или статус продукта) в отдельной колонке или сноске для команды.

## 2. Фреймворки
| Фреймворк | Шаги | Когда |
|---|---|---|
| PAS | Problem → Agitate → Solution | Problem Aware, универсальный |
| PAS по NSY | Проблема → Неудачные решения → Мост → Продукт → Преимущества → Призыв | высокая изощрённость |
| AIDA | Attention → Interest → Desire → Action | почти всегда |
| QUEST | Qualify → Understand → Educate → Stimulate → Transition | нужно объяснять; Solution/Product Aware |
| Enemy | Общий враг → почему вредит → мы против → продукт | высокая изощрённость, сильная позиция |
| Outcome | Результат → как получен → продукт | результат сам цепляет |
| BAB | Before → After → Bridge | трансформация, отзывы |
| История основателя | Почему существует → открытие → доказательство → возражения | основатель сам авторитет |

## 3. Доказательства — под возражение
Типы:
- демонстрация;
- до/после и прогресс во времени;
- отзыв покупателя;
- цифры (рейтинг, число отзывов, продажи);
- эксперт;
- пресса и награды;
- сравнение;
- механизм и факты;
- гарантия.

Выбирай под конкретное возражение, лучше визуальное. Примеры NSY:
- «ничего не помогало» → прогресс на 1, 7, 30 день;
- «удобные ли джинсы» → человек приседает в них.

Для сумок:
- «тяжёлая?» → весы, пустая и с ноутбуком;
- «влезет под сиденье?» → реальный замер в салоне или по размерам авиакомпании.

Не выдумывай прессу, награды, рейтинги и отзывы. Отзыв в ролике — только реальный, дословный, с разрешения или из публичного источника по правилам площадки.

## 4. CTA
Что сделать (конкретно) + почему сейчас (честно) + почему без риска (гарантия, возврат). Мягкость по уровню: Problem Aware → «посмотри, как работает», Most Aware → прямой оффер. Пример: "Tap Shop Now to see all colors", а не «узнай больше».

## 5. Платформы (2026)
- **Meta:** 9:16 (Reels, Stories) и 4:5 / 1:1 (лента). Верх и низ Reels закрыты интерфейсом, текст держи в центре. Многие смотрят без звука, нужны субтитры.
- **TikTok:** нативность важнее всего, звук включён. Spark Ads через пост бренда или креатора (права обычно на 6–12 месяцев). Креатив быстро «съедается».
- **YouTube:** Shorts 9:16. In-stream пропускают через 5 секунд, поэтому хук и бренд в первые 5 секунд. ABCD: Attention, Branding (рано и не раз), Connection, Direction.

Бренд внутри перформанса: отличительные активы (лицо, фраза, звук) повторяй одинаково.

Референс: один главный. Можно брать 60–80% успешного референса, меняя детали под продукт и аудиторию.

## 6. Бриф для монтажёра (16 блоков)
1. Концепт (название, одна фраза).
2. Цель и метрика успеха (с ориентиром).
3. Кому (персона).
4. Уровень осведомлённости.
5. Инсайт (с вердиктом).
6. Главное сообщение.
7. Скелет по секундам с «зачем».
8. 3 хука, каждый в трёх слоях.
9. Доказательства.
10. Оффер и CTA (точный текст).
11. Обязательно (бренд, оффер, дисклеймеры, активы).
12. Нельзя (утверждения `НУЖЕН ТЕСТ` / `НЕЛЬЗЯ`).
13. Тон и темп.
14. Один главный референс и что из него взять.
15. Технически (форматы, длины, версии под хуки).
16. Материалы.

## 7. Бриф для UGC-креатора
Не дословный скрипт (он убивает живость), а:
- 3–4 факта о продукте (только подтверждённые);
- кому говоришь;
- 3–4 ключевые мысли своими словами;
- 3–5 хуков отдельными дублями;
- **речь и персона** из `personas-speech.md`: как звучать, примеры и антипримеры;
- список кадров;
- надо / нельзя;
- технически: вертикально, свет, звук, без музыки;
- права на использование.

## 8. Бриф для статики
- главная мысль;
- заголовок 5–8 слов;
- визуал;
- доказательство;
- CTA;
- обязательно;
- размеры 1:1, 4:5, 9:16.

Типы: заголовок + продукт; отзыв крупно; «мы против них»; «заметка»; «обзорная статья».

## 9. Страница после клика
1. Первый экран продолжает обещание рекламы.
2. Оффер виден.
3. Главное возражение снято выше середины.
4. Доказательство рядом с кнопкой.

Типы:
- страница товара (Product/Most Aware);
- лендинг под концепт;
- advertorial или листикл (Unaware/Problem Aware);
- квиз (когда нужен выбор).

Если страница не совпадает с роликом, скажи это пользователю: часть «плохого креатива» на деле плохая страница.

## 10. Язык брифа
По умолчанию бриф по-русски, реплики и тексты на экране на языке рынка (обычно английский). Если исполнитель англоязычный, сделай полную английскую версию: без кириллицы, с теми же фактами, ссылками и оговорками. Перед отдачей сверь, что ничего не потерялось.

## Где лежит
Скрипт — вкладка `Скрипт` (`Скрипт 2`, `Скрипт 3` для остальных). Бриф — вкладка `Бриф` или Google Doc в папке ресерча, если пользователь попросит документ. Если пользователь работает со `storyboard-video-engine` или `video-gen-prompter`, предложи передать скрипт туда.
