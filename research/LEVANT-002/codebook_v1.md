# LEVANT-002 · Кодбук кластеров v1 (волна 1, предварительный)

Кластер = мысль человека. Новые кластеры добавляются по ходу (P09, D06 …) с названием.

| ID | Мысль клиента |
|---|---|
| P01 | Подкладка пачкается, и нутро сумки нормально не почистить |
| P02 | Внутри что-то протекло или пролилось (косметика, ручка, еда, напиток), и сумка испорчена или пахнет |
| P03 | Почистила или постирала сумку и испортила её (пятна от воды, потускнела, деформировалась) |
| P04 | Подкладка разрушается сама: липнет, облезает, рвётся |
| P05 | Сумка как «чёрная дыра»: ничего не найти, нет карманов |
| P06 | Тёмная (чёрная) подкладка: внутри ничего не видно |
| P07 | Тяжело, болит плечо (вторично) |
| P08 | Красивая сумка оказалась непрактичной в жизни |
| D01 | Хочу сумку, которая выглядит дорого и собранно и при этом практична |
| D02 | Хочу съёмную или моющуюся подкладку |
| D03 | Хочу отделения и порядок внутри |
| D04 | Хочу, чтобы корпус легко протирался или не боялся грязи |
| O01 | Веганская кожа / PU выглядит дёшево или облезет |
| O02 | Не стоит своих денег, цена |
| O03 | Не доверяю бренду, качеству, сервису |
| O04 | Отделения и карманы мешают, лучше одно большое пространство |
| E01 | Обхожусь вкладышем, органайзером или косметичками внутри |
| E02 | Стираю или чищу сумку сама: что вышло |
| X01 | Не чищу сумку и не переживаю (контрдовод) |
| X02 | Подкладка не нужна, лучше без подкладки (контрдовод) |
