# Разметка цитат и кластеры

## Что считать цитатой
Одна мысль одного человека. Если в отзыве три разные мысли (боль, желание, возражение), это три строки VOC с одним URL. Берём дословно, можно обрезать до сути с «…».

Не брать: рекламные тексты брендов, SEO-статьи без мнений, комментарии без смысла («nice bag!»), если только они не показательны для языка.

## Поля разметки

| Поле | Значения |
|---|---|
| Тип | `Боль`, `Желание`, `Возражение`, `Триггер`, `Опыт` (что пробовал и чем кончилось), `Язык` (яркая фраза, полезная для хука) |
| Тема | короткая метка: `плечо/спина`, `органайзер`, `ноутбук`, `ручная кладь`, `безопасность`, `стиль`, `цена`, `качество`, `вес`, `вместимость`, `бренд/доверие`, `уход/материал` и т.д. Новые темы добавляй по мере появления |
| Персона | гипотеза: `путешественница 50+`, `офис/коммьют`, `мама`, `медсестра/учитель`, `студентка`, `бизнес-трип`, `не ясно` |
| Эмоция | `раздражение`, `стыд`, `тревога`, `облегчение`, `гордость`, `зависть`, `радость`, `разочарование` |
| Кластер | ID вида `P01` (боль), `D01` (желание), `O01` (возражение), `T01` (триггер), `E01` (опыт) |
| Сила | 1–3: насколько эмоционально и конкретно сказано (3 = готовая фраза для хука) |

## Как кластеризовать
1. После первых 40–60 цитат прочитай их подряд и выдели повторяющиеся мысли, дай им ID и короткое название в вкладке «Кластеры».
2. Дальше каждую новую цитату относи к существующему кластеру или создавай новый.
3. Кластер формулируй как мысль человека, а не как тему: не «Плечо», а «Тяжёлый тоут с ноутбуком натирает плечо к концу дня».
4. Слишком большой кластер (> 25% всех цитат) раздели на подкластеры.
5. Частоту считают формулы в таблице (`COUNTIF` по колонке «Кластер» во VOC), не пиши число руками.
6. Для каждого кластера выбери 2–3 лучшие цитаты (сила 3): они пойдут в хуки и скрипт.

## Что смотреть после кластеризации
- **Топ по частоте**: массовые боли и желания, база для масштабируемых углов.
- **Высокая эмоция при средней частоте**: сильные хуки для отдельных персон.
- **Противоречия**: люди хотят A и одновременно B, которые кажутся несовместимыми. Отсюда лучшие инсайты.
- **Различия по рынкам и персонам**: фильтр по колонкам «Рынок» и «Персона».
- **Пустые места**: вопросы ресерча, на которые цитат мало. Либо добрать, либо отметить пробел.
