# Концепт и скрипт

## Карточка защиты концепта
Каждый концепт должен выдерживать вопрос «почему именно этот ролик?». Заполни все поля, иначе концепт не готов.

| Поле | Что писать |
|---|---|
| Название | 3–6 слов |
| Идея одной фразой | «Показываем, как…» |
| Продукт | какой из продуктов Nordace |
| Персона и уровень осведомлённости | из вкладки «Персоны» |
| Угол | из вкладки «Углы» |
| Какую боль/желание закрывает | кластеры с ID и частотой: «P03, 34 из 212 цитат, 4 площадки» |
| Инсайт | формула: наблюдение + почему + значит |
| Почему сейчас | сезон, тренд, событие (например, новые правила ручной клади), пробел у конкурентов |
| Чем отличается от конкурентов | что они показывают и в чём наш ролик другой |
| Доказательство в кадре | что зритель увидит своими глазами |
| Хуки | 3–5 вариантов разных типов |
| Формат | UGC, talking head, демонстрация, сравнение, «что в сумке», скетч |
| Длина | 15–30 с для холодного трафика, 30–60 с для сложного продукта/демонстрации |
| Масштабируемость | почему зайдёт широкой аудитории, а не узкой нише |
| Гипотеза и как проверить | что должно произойти с метриками: «hook rate ≥ 30% подтвердит, что боль узнаётся; CTR ≥ 1.2% подтвердит интерес к решению» |
| Риски | что может не сработать |

## Структура скрипта
Для лучшего концепта пиши скрипт таблицей:

| Время | Кадр (что видно) | Текст на экране | Voice-over / речь | Задача сцены |
|---|---|---|---|---|
| 0–3 с | … | … | … | Хук: остановить скролл |
| 3–8 с | … | … | … | Проблема: узнавание |
| 8–20 с | … | … | … | Решение: продукт в действии, главная фича |
| 20–27 с | … | … | … | Доказательство: отзывы, тест, сравнение |
| 27–30 с | … | … | … | CTA: что сделать и почему сейчас |

Правила:
- Продукт в кадре как можно раньше (к 3–5 секунде), особенно для холодной аудитории.
- Каждые 2–3 секунды что-то меняется в кадре: смена плана, действие, текст. Так держится hold rate.
- Текст на экране дублирует главную мысль: многие смотрят без звука.
- Одна главная выгода на ролик. Остальные фичи можно показать мельком.
- CTA конкретный: "Tap Shop Now to see all colors", а не «узнай больше».
- Под каждый хук из карточки можно смонтировать отдельную версию первых 3 секунд с одним и тем же телом ролика: так тестируются хуки.
