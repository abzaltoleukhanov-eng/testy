# Разметка цитат и кластеры

## Что считать цитатой
Одна мысль одного человека. Если в отзыве три разные мысли (боль, желание, возражение), это три цитаты с одним источником. Цитата дословная; длинную можно сократить через «...». Скрипт проверит, что каждый кусок есть в оригинале, по порядку.

Не брать:
- тексты брендов и SEO-статьи без мнений;
- пустые комментарии («nice bag!»), если только они не показательны для языка;
- пересказы.

Не путать **жалобу** и **решение**:
- «Мне не нравится тяжесть» — это `Боль`, действие `NONE`.
- «Я вернула сумку, потому что с ноутбуком она слишком тяжёлая» — это `Решение`, действие `RETURNED`, причина названа самим человеком.

Но рассказ о покупке не доказывает её настоящий мотив: это пишется в `note`.

## Поля (для `voc.py add-quotes`)
| Поле | Значения |
|---|---|
| `source` | id сохранённого текста из `show` (`rd:...`, `yt:...`, `wf:...`, `us:...`, `pg:...`) |
| `quote` | дословно |
| `translation` | перевод на русский (для английских цитат обязательно) |
| `type` | `Боль` · `Желание` · `Возражение` · `Триггер` · `Опыт` (что пробовал и чем кончилось) · `Решение` (купил / отказался / вернул / перешёл) · `Язык` (яркая фраза для хука) · `Контрдовод` (опровергает нашу догадку) |
| `theme` | короткая метка: `плечо/спина`, `вес`, `ноутбук`, `органайзер`, `ручная кладь`, `безопасность`, `стиль`, `цена`, `качество`, `материал`, `бренд/доверие`, `доставка`… Новые добавляй по ходу |
| `persona` | гипотеза: `путешественница 50+`, `офис/коммьют`, `мама`, `медсестра/учитель`, `бизнес-трип`, `не ясно`. Возраст и пол только если человек назвал их сам |
| `emotion` | `раздражение`, `стыд`, `тревога`, `облегчение`, `гордость`, `зависть`, `радость`, `разочарование` |
| `cluster` | `P01` боль · `D01` желание · `O01` возражение · `T01` триггер · `E01` опыт/решение · `X01` контрдовод |
| `strength` | 1–3: насколько эмоционально и конкретно (3 = готовая фраза для хука) |
| `action` | что человек **сделал**: `NONE` `CONSIDERED` `POSTPONED` `BOUGHT` `REJECTED` `RETURNED` `SWITCHED` `USES` `STOPPED_USING` `WORKAROUND` `RECOMMENDS` |
| `market` | только если виден (площадка или слова в тексте); иначе пусто |
| `note` | что эта цитата **не** доказывает, контекст, «реклама/аффилиат», если автор получает комиссию |

Записывай пачками по 30–80 цитат одним JSON-файлом. Если скрипт отклонил цитату, открой источник (`show`) и возьми точный текст. Поправить кластер или персону можно через `retag`, но не текст цитаты.

## Независимость: почему «30 цитат» может быть одним мнением
- Комментарии одного треда — одна **группа**: люди повторяют автора поста и друг друга. Скрипт считает и группы (треды, видео, страницы), и авторов отдельно.
- Один автор с пятью комментариями — один голос.
- Отзывы на сайтах отзывов — независимые люди (`--each-independent`).
- Аффилиат-обзор, реклама, «got this for free» — пометь в `note`. Это не независимое мнение покупателя.
- Одинаковые тексты на разных сайтах (перепечатки) не считаются дважды.

## Кластеры
1. После первых 40–60 цитат прочитай их подряд и выдели повторяющиеся мысли: ID и короткое название на вкладку `Кластеры`.
2. Каждую новую цитату относи к существующему кластеру или создавай новый.
3. Формулируй кластер как мысль человека, а не тему: не «Плечо», а «Тоут с ноутбуком к вечеру режет плечо».
4. Кластер больше 25% цитат раздели на подкластеры.
5. Группируй по ситуациям и решениям, а не только по «болям». «Упаковка» может значить и список в голове перед поездкой, и компромисс в одежде, и ручную кладь: это разные кластеры.
6. Частоту не пиши руками. В таблице её считают формулы, в проекте `voc.py stats` (цитаты, независимые треды, авторы, площадки).
7. Для каждого кластера выбери 2–3 лучшие цитаты силы 3: они пойдут в хуки и скрипт.

## Что смотреть после кластеризации
- **Топ по независимым тредам и авторам:** массовые боли и желания, база масштабируемых углов.
- **Высокая эмоция при средней частоте:** сильные хуки для отдельных персон.
- **Противоречия** (хотят A и одновременно B, которые кажутся несовместимыми): отсюда лучшие инсайты.
- **Решения:** что заставило купить, отказаться, вернуть. Это ближе всего к деньгам.
- **Различия по рынкам и персонам:** фильтр по колонкам.
- **Пустые места:** вопросы ресерча, на которые цитат мало. Либо добрать, либо отметить пробел.
