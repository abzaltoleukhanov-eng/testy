# Доступ к источникам: откуда и как брать голос покупателя

Ресерч имеет смысл, только если каждую цитату можно открыть по ссылке и увидеть те же слова. Поэтому:
- у каждого текста есть **маршрут** (как получен);
- у каждого текста есть **статус** (насколько ему верить).

Сниппет из поиска — это наводка, где искать, а не цитата.

## Статусы
| Статус | Что значит | Можно в цитату? | Сильный? |
|---|---|---|---|
| `VERBATIM` | скрипт прочитал полный текст оригинала или его архива | да | да |
| `BROWSER` | агент прочитал текст страницы в браузере пользователя (Claude in Chrome или браузер в приложении Claude) | да | да |
| `USER` | пользователь вставил текст или прислал скриншот, ты переписал его дословно | да | да |
| `WEB_CONFIRMED` | короткая точная фраза из WebFetch, подтверждённая вторым независимым чтением | да | да |
| `WEB_QUOTE` | короткая фраза из WebFetch, ещё не подтверждённая | только в черновик | нет |
| `WEB_UNCONFIRMED` | второе чтение фразу не нашло | нет | — |

«Сильные» статусы нужны скрипту, чтобы признать инсайт подтверждённым (`check-insights`).

## Что откуда открывается
Проверено из облачной среды Claude Code (октябрь 2026). Проверяй в начале каждого ресерча: доступ меняется.

| Площадка | Облако (claude.ai/code) | Компьютер пользователя | Маршрут и команда |
|---|---|---|---|
| **Reddit** | да, через архив Arctic Shift: полные треды, дословно, ссылка на каждый комментарий. Сам reddit.com отвечает 429 (лимит) | то же + живой reddit.com | `reddit-find` (поиск внутри сабреддита), `reddit-thread` (тред целиком) |
| **YouTube** | да, через yt-dlp: поиск, комментарии со ссылкой на каждый, субтитры | да | `yt-find`, `yt-comments [--subs]` |
| **Trustpilot** | только WebFetch: точная фраза до ~125 знаков + пересказ | WebFetch или браузер | `web-add --each-independent`, затем `web-confirm` |
| **Mumsnet** | только WebFetch (прямой запрос упирается в проверку Cloudflare) | браузер даёт полный текст | `web-add`, `web-confirm`; в браузере `user-add --route BROWSER` |
| **Форумы** (MoneySavingExpert и другие без проверки на бота) | часто да, напрямую, полный текст страницы | да | `web-page`; если 403, то WebFetch и `web-add` |
| **Facebook-группы, комментарии под рекламой** | нет (нужен вход) | да, в браузере пользователя, если он участник группы | `user-add --route BROWSER` или скриншоты, `user-add` |
| **Meta Ad Library** | нет | да, в браузере пользователя | вручную по полям из `competitors-formats.md`, `user-add --route BROWSER --kind Конкурент` |
| **Amazon, сайт Nordace** | нет (403 / 503) | обычно да | браузер или скриншоты страницы |
| **TikTok, Instagram** | нет | частично (скилл `tiktok-grab` качает видео, комментарии вручную) | скриншоты, `user-add` |
| **Поиск ссылок** | WebSearch (только сниппеты и ссылки) | то же | `log-search`, потом открыть каждую ссылку своим маршрутом |

**Вывод для пользователя.** В облаке надёжно работают Reddit, YouTube и часть форумов: это сотни дословных цитат. Trustpilot и Mumsnet дают короткие подтверждённые фразы. Facebook-группы, Ad Library, Amazon и сайт Nordace требуют его браузера. Лучший режим для полного ресерча — Claude на компьютере пользователя с расширением Claude in Chrome: тогда агент читает страницы под его логинами, в том числе Facebook-группы, где он состоит. Перед первым использованием браузера загрузи скилл `chrome-browser` (или `built-in-browser` для браузера в приложении Claude).

## Проверка за минуту
```bash
V="python3 scripts/voc.py --project-dir <абс. путь>/research/<ID>"
$V reddit-find --subreddit handbags --q tote --limit 5 --branch B00 --polarity NEUTRAL   # архив Reddit
python3 -m yt_dlp --version || pip install yt-dlp                                        # YouTube
curl -s -o /dev/null -w "%{http_code}\n" -m 15 https://forums.moneysavingexpert.com/    # прямые форумы
```
WebFetch проверь одной страницей Trustpilot. Браузер: если есть инструменты `mcp__claude-in-chrome__*` или `mcp__Claude_Browser__*`, он доступен.

Если не открывается ничего (код 000, ошибка прокси), скажи пользователю: сетевая политика окружения закрыла внешние сайты. Как исправить: в Claude Code меню облачного окружения → Edit → Network access → **Full**, затем новая сессия (https://code.claude.com/docs/en/claude-code-on-the-web). Пока доступа нет, можно сделать только бриф, план запросов и разбор того, что пришлёт пользователь.

## Как работать с каждым маршрутом

### Reddit (архив Arctic Shift)
1. **Найти треды.** Есть два способа, используй оба.
   - **WebSearch** по всему Reddit: `allowed_domains: ["reddit.com"]`, запрос на английском («work tote laptop shoulder pain»). Залогируй через `log-search --platform reddit`, затем открой нужные треды `reddit-thread <url> --query SQxxx`.
   - **Внутри сабреддита**: `reddit-find --subreddit HerOneBag --q tote` ищет по тексту постов. С `--kind comments` ищет по тексту комментариев. Лучше всего работают 1–2 слова. Длинные фразы архив часто не выдерживает (таймаут), скрипт сам повторяет запрос с паузой.
2. **Сохранить тред:** `reddit-thread <url или id> --query SQxxx --market US`. Сохраняются пост и все комментарии, у каждого постоянная ссылка `reddit.com/r/<sub>/comments/<тред>/comment/<id>/`.
3. **Прочитать:** `show S0xx --min-len 80` (короткие комментарии вроде «+1» скрываются).
4. Ограничения, которые нужно называть пользователю:
   - архив — это снимок, текст мог быть потом отредактирован или удалён на сайте;
   - треды последних дней могут быть неполными;
   - ветки за ссылками «more» архив иногда не отдаёт (скрипт показывает их число).

### YouTube (yt-dlp)
- `yt-find --q "nordace tote review"` ищет видео, показывает просмотры и канал.
- `yt-comments <url> --max 300` сохраняет комментарии, у каждого ссылка `watch?v=<id>&lc=<comment_id>`. С `--subs` сохраняется ещё и расшифровка речи: материал для этапа «речь персоны» и для разбора форматов.
- Ответы автора видео помечены `by_uploader`. Ролики самого Nordace сохраняй с `--kind "Наш бренд"`: комментарии под ними — голос наших покупателей и скептиков.

### WebFetch (Trustpilot, Mumsnet, закрытые форумы)
WebFetch проходит проверку на бота, но отдаёт текст через вспомогательную модель: пересказ и точную фразу не длиннее ~125 знаков. Поэтому чтений два.
1. **Первое чтение** (промпт): «For each post/review return: author, date, rating, the post's own URL if shown, one EXACT phrase copied character for character (max 120 characters), and a one-sentence paraphrase. Do not merge posts.» Сохрани ответ JSON-файлом и запиши: `web-add --platform trustpilot --url ... --title ... --each-independent @posts.json`. Флаг `--each-independent` ставь для сайтов отзывов, где каждый отзыв — отдельный человек. Для треда форума его не ставь: тред считается одной группой.
2. **Второе чтение** (отдельный вызов, другой промпт): «For each phrase answer FOUND or NOT_FOUND: does this exact wording appear on the page? Give the author.» Передай только те фразы, которые пойдут в цитаты. Затем `web-confirm <ids> --result yes` (или `no` для ненайденных).

Никогда не пиши в поле `quote` свои слова. Если инструмент дал только пересказ, пост не сохраняй: он годится только как наводка.

### Браузер пользователя (Facebook, Ad Library, Amazon, сайт Nordace)
- Открой страницу в новой вкладке, прочитай текст страницы инструментом браузера, перепиши нужные посты дословно и запиши каждый: `user-add --route BROWSER --platform facebook --title "<группа>: <тема поста>" --url <ссылка на пост> --author "<имя>" --date ... --text @post.txt`.
- В Facebook-группах ссылка на конкретный пост: «…» у поста → «Копировать ссылку», или дата поста. Закрытые группы видит только участник: сама ссылка у других не откроется, это надо отметить в `--notes`.
- Не пиши в группы, не реагируй, не вступай в группы и не меняй ничего от имени пользователя.

### Материалы пользователя
Скриншоты, выгрузки, вставленный текст: `user-add --platform ... --text @file`. Переписывай со скриншота дословно, с опечатками. Ссылку указывай, если она есть.

## Журнал запросов
Каждый поиск, удачный или пустой, попадает в `queries.jsonl` (скрипт пишет сам, для WebSearch используй `log-search`). Указывай:
- `--branch` — ветку поиска;
- `--polarity` — тон запроса (`PROBLEM`, `NEUTRAL`, `POSITIVE`, `SWITCH`, `COUNTER`);
- `--stage` — этап пути покупателя;
- `--why` — какая цитата привела к этому запросу.

Журнал показывает пользователю, что именно искали. Без него «ничего не нашли» нельзя отличить от «не искали».
