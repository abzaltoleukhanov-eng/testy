# От продукта к сообщению и концептам

## 1. Сообщение
- **Характеристика → выгода → выгода выгоды** (`product.md`). Ведёт выгода выгоды, характеристика доказывает.
- **УТП** = то, что можем сказать только мы, **и** что важно покупателю. На высокой стадии изощрённости УТП — это механизм.
- **Формула ценности (Хормози):** Ценность = (Желаемый результат × Уверенность, что получится) ÷ (Время до результата × Усилия и жертвы). Для каждой части запиши, что бренд может сделать. Проверь, не сидит ли главный страх покупателя в знаменателе («тяжело носить», «долго разбираться»): реклама, которая расписывает только результат, его не снимет.
- **Карта сообщений:** главное обещание; 3 опоры; доказательство под каждую (статус из `product.md`); ответы на 3 главных возражения.

## 2. Механизмы: почему люди так поступают
Механизм — психологическая причина поведения, на которую опирается ролик. Формула: **«хочу X, но Y, поэтому делаю Z»**.

Если есть инструмент агентов, запусти 3–4 агента с разными линзами. Каждый видит только выгрузку: кластеры, инсайты с вердиктами, цитаты-решения.
- **Антрополог:** ритуалы, обходные решения, идентичность, дела против слов.
- **Копирайтер прямого отклика:** напряжение, страх, желание, язык покупателя.
- **Поведенческий экономист:** потери, якоря, сожаление, проверка перед покупкой, статус-кво.
- **Контрарианец:** что вся категория говорит, а люди опровергают поведением.

Затем отдельный проход склеивает дубли. Два механизма разные, только если предсказывают разное поведение или требуют разного хука.

Семейства (чтобы считать разнообразие):
- идентичность и внешний вид;
- потеря и сожаление;
- доверие и проверка;
- усилие и трение;
- ритуал и обходное решение;
- контроль и тревога;
- социальный сигнал;
- деньги и ценность.

Если все механизмы из 1–2 семейств, это пробел.

## 3. Уровни идеи
Угол (через какую мысль) → **концепт** (кому × угол × оффер) → формат → исполнение → хук (1–3 с) → вариация. Чем выше уровень, тем сильнее изменение. Почти одинаковые объявления Meta (Andromeda) воспринимает как одно, поэтому тестовые объявления должны различаться выше уровня вариации.

**Концепт = персона × угол × оффер.**
- Поменял одно из трёх — это новый концепт.
- Поменял креатора, музыку, первый кадр — это вариация.

Оффер должен снимать главный страх персоны.

Идея может быть верной по углу и провалиться на обещании («исчезнет за 60 секунд» → «over-promise, not believable») или на языке («dry AF» для аудитории 50+ → «too socially native»). Проверяй концепт целиком.

## 4. Источники углов
1. Главное желание.
2. Боль.
3. Возражение.
4. Враг (против чего мы).
5. Механизм.
6. Результат / трансформация.
7. Идентичность (кто ты).
8. Момент-триггер.
9. Социальное доказательство.
10. Цена бездействия.

Плюс соседние категории: форматы, которые работают у брендов той же аудитории.

**Точки входа в категорию** (Романюк, Шарп): ситуации, в которых человек вспоминает о сумке. Например: «авиакомпания ввела плату за ручную кладь», «новая работа в офисе», «порвалась ручка у старой», «первая поездка после рождения ребёнка». Разные концепты — под разные точки входа.

Библиотека углов для сумок (подсказки, каждый угол обязан ссылаться на кластер):

| Тип | Пример |
|---|---|
| Проблема → решение | «Плечо болит от тоута с ноутбуком? Превращаем в рюкзак» |
| Ручная кладь / personal item | «Влезает под сиденье, вмещает на 5 дней» |
| Одна вместо многих | «Офис → спортзал → самолёт: одна сумка» |
| Порядок в хаосе | «Больше не ищу ключи на дне сумки» |
| Безопасность | «Молния у спины» |
| Дорогой аналог | «Как Béis, только …» (только честное, проверяемое сравнение) |
| Демонстрация вместимости | «Упаковала 5 дней в тоут» |
| Идентичность | «Для женщин, которые путешествуют сами» |
| Подарок / сезон | «Подарок маме, который она будет носить каждый день» |
| Возражение в лоб | «Думала, развалится через месяц. Год спустя…» (только с реальным отзывом) |
| Анти-совет | «Хватит носить ноутбук в обычном тоуте» |

## 5. Матрица углов (вкладка `Углы`)
| Угол | Персона | Кластер | Осведомлённость | Почему сработает | Доказательство | У конкурентов | Масштаб 1–3 | Пробел 1–3 | Доказуемость 1–3 |

- **Масштаб:** независимые треды и авторы кластера, широта персоны. Самый важный критерий: победителю нужно $50–100k спенда.
- **Пробел:** 3 = никто из конкурентов так не говорит, 1 = все.
- **Доказуемость:** 3 = видно в кадре за 3 секунды.

## 6. Карточка защиты концепта (вкладка `Концепты`)
| Поле | Что писать |
|---|---|
| Название | 3–6 слов |
| Идея одной фразой | «Показываем, как…» |
| Продукт | SKU |
| Персона и осведомлённость | из `Персоны` |
| Угол и механизм | из `Углы`, семейство механизма |
| Оффер | что получает и что снимает страх |
| Инсайт | формула + вердикт скрипта + аудит |
| Цитаты в основе | ID и ссылки на 3–5 лучших |
| Контрдоводы | что ему противоречит и почему всё равно стоит пробовать |
| Сдвиг убеждения | было «…» → стало «…» |
| Почему сейчас | сезон, правила, пробел у конкурентов (с источником) |
| Чем отличается от конкурентов | что показывают они и в чём мы другие |
| Конфликт и развязка | что мешает герою и что он чувствует в конце |
| Доказательство в кадре | что зритель увидит своими глазами |
| Хуки | 3–5 (`hooks.md`) |
| Формат | из поиска форматов, со ссылкой на пример |
| Длина | 15–30 с холодный трафик; 30–60 с для демонстрации |
| Масштабируемость | почему зайдёт широкой аудитории |
| Что нельзя говорить | утверждения со статусом `НУЖЕН ТЕСТ` / `НЕЛЬЗЯ` |
| Гипотеза теста | `priorities-test.md` |
| Риски | что может не сработать |
| Статус | `Идея` / `Отклонён: <причина>` / `В производстве` / `В тесте` / `Победитель` / `Не сработал` |

**Проверка заменой.** Замени продукт безымянной сумкой. Если концепт не ломается, роль продукта декоративная, концепт не годится. Продукт должен быть причиной развязки через конкретную фичу со статусом `ПОДТВЕРЖДЕНО`.

**Файрвол фактов.** Всё фактическое в концепте и скрипте либо подтверждено (цитата или продукт), либо помечено «гипотеза». Нельзя писать без основания:
- «доказано»;
- «легче конкурентов»;
- «никогда не сломается»;
- проценты людей.

**Отклонённые концепты не удаляй:** статус `Отклонён` и причина. Это защищает от повторения тех же ошибок.

## 7. Проверка разнообразия портфеля (6–10 идей до отбора)
1. Разные ли желания?
2. Разные ли персоны?
3. Разные ли уровни осведомлённости?
4. Разные ли форматы?
5. Различаются ли первые 3 секунды визуально?
6. Разные ли семейства механизмов?

Итерация улучшает победителя (хук, формат, креатор). Новый концепт ищет следующего (персона, угол, оффер). Нужны оба. Если у пользователя есть победитель, предложи и итерацию, и новый концепт.
